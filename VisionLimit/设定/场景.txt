【密码叙事逻辑：内部注释（设计用，不对玩家显示）】

① 「0804」为什么是「只有她自己记得的那个日子」
2046年8月4日，郑和平完成精炼厂附近的最后一次野外采样，随即将四年积累的全部异常数据强行写入自己的记忆海——她清楚这个操作会引发记忆紊乱，但那是她能想到的唯一安全容器。写入完成后，她陷入重度昏迷，被送入苍屿第一医院。

② 她为什么要把它写下来
出发前，郑和平预判了危险：临深集团一直在密切监视她的行动，写入记忆海这个操作本身是高风险且不可逆的。
③ 魏江怎么知道，以及他已经知道什么
魏江原是海岸时讯的调查记者。2046年初，他已离开旧媒体独立出来，在追苍屿县儿童神经损伤病例的线索时，辗转接触到了正在做相同方向调查的郑和平。两人有过一次见面。郑和平当时数据已经基本积累完毕，决定好了写入记忆海的时间，她把录音笔交给魏江保管，告诉他「密码是个日子，只有我自己知道是哪天，你以后会知道的」。
魏江当时的稿子——写苍屿儿童病例、指向近海排污的那篇——在准备发出时被媒体方以「证据不足，不具说服力」为由压下。
郑和平进了医院之后，他解开了录音笔，听完了全部内容。但他并不知道郑和平的未尽之意，但他推测是被写入到了记忆海中。
他接下来花了更长的时间才找到沈意——那个在记录里进出郑和平病房十一次、最后一次是2046年12月17日的人。他知道那份数据现在应该已经不在郑和平身上了。但他不知道它是否真的消失了，还是以某种形式留在了接触过她记忆海的人身上。

核心谜题：「纸面核验」

谜题触发条件：
  玩家依次查看电子价牌、渔获筐标签、码头泊位告示牌、冷库门口告示后，沈意说：
  「每一张纸都在解释另一张纸。但谁来解释第一张？」
  谜题界面弹出。

谜题说明：
  场景内所有的"书面陈述"彼此背书，构成一个闭合的自我验证体系——但每条陈述都与场景内的某个实物证据直接矛盾。
  玩家将左列的4条书面陈述与右列能直接推翻它的实物证据配对。

左列（书面陈述，来自场景内文字材料）：
  A  价牌旁手写便签——「供应稳定，请放心选购。」
  B  冷库门口告示——「货品损耗属正常海运波动范围，品质经相关部门核验。」
  C  渔获筐标签——来源CY-0887，捕捞日期2050.03.07，入库时间09:30
  D  电子价牌——C-03区·黄鱼中条·今日价11元/斤（🔴特价）

右列（实物矛盾证据，来自同场景叙事静物，打乱顺序显示）：
  1  电子价牌同栏：A-02区同规格黄鱼中条今日价42元/斤——差价约75%，非季节性波动
  2  码头泊位告示牌：03号泊位·CY-0887·作业中，预计明日返港（船不在港，入库无从发生）
  3  冷库外墙公示栏：损耗率原值18-25%被涂改为3%，核验章盖在改后版本上
  4  现场实况：C-03区货筐单独堆放，与主道货物有明显间距；渔民受访表示「我们自己不吃那边的鱼」

正确匹配：A→4 / B→3 / C→2 / D→1

关键干扰项说明：
  A和C看起来都指向"产品本身有没有问题"，但角度不同——
  · A 是商户给顾客的口头保证，被顾客的真实行为（回避）直接否定（向消费者端看）
  · C 是行政记录上的时间戳，被另一条行政记录（泊位状态）直接否定（向系统内部看）
  B和D看起来都和"数字"有关，但推翻方式不同——
  · B 的核验被推翻是因为核验对象本身已被篡改（核验章盖在假数字上）
  · D 的价格被推翻是因为同场景有可比较的对照数字（差价揭示异常）
  玩家若将A和C互换、或将B和D互换，系统标红对应连线，提示重选。

操作规则：
  · 点击左侧书面陈述 → 陈述卡高亮
  · 再点击右侧实物证据 → 绘制连线，双侧标记为已配对
  · 点击已有连线可撤销，无失败惩罚，可无限重选
  · 四对全部连对后触发完成逻辑

完成结果：
  沈意说：「每一张纸都解释了另一张纸——但解释本身是假的。」
  [记录：C-03区渔获数据链——从标签到告示，完整的自我背书造假结构] → 加入发现栏

叠加触发（非谜题，观察奖励）：
  玩家在谜题界面激活后点击右区精炼厂烟囱，额外触发沈意独白：
  「排污口在水下。这里这些数字，证明不了那边发生了什么。」
  不影响谜题进度，仅作情感补充。

      if is_left:
          first_selected = id
      elif first_selected != "":
          matched_pairs[first_selected] = id
          draw_connection_line(first_selected, id)
          first_selected = ""
          check_completion()

  func _on_line_clicked(pair_key: String):
      matched_pairs.erase(pair_key)   # 点击已有连线可撤销

  func check_completion():
      if matched_pairs.size() < 4: return
      for key in correct_map:
          if matched_pairs.get(key) != correct_map[key]:
              highlight_wrong_lines()
              return
      trigger_success()

【核心谜题】「时间轴归档」

触发条件：玩家查看完荣誉牌匾、旧报纸、打印机旁材料、档案柜、便利贴和旧工位后自动触发。
沈意会说：
「这些东西不是散的，是被人按年份切开了。」

玩法结构：
  1. 左侧显示 4 张可点击的档案材料卡，右侧显示 4 个年份格位。
  2. 玩家先点材料，再点目标年份格，将材料归档到对应年份。
  3. 放错时材料会退回原位并闪红，不扣次数，可反复调整。
  4. 四份材料全部归位后，系统自动进入核验状态，玩家需要确认 2041 年的荣誉附件与 2044 年的数字化销毁单彼此并不矛盾，真正矛盾的是“实体文件已销毁，却还保留了可追溯的归档路径”。

左侧材料卡（来源于场景内物件的归档摘要）：
  A. 2040 年水质年度监测报告
     - 关键字：苍屿近海、水质、公开比对标准
     - 说明：最早的基准档，代表“正常年份”的基线

  B. 2041 年荣誉附件
     - 关键字：省级达标示范单位、临深集团配合检测情况说明、勿遗失
     - 说明：表面上是荣誉，实际上把“配合检测”写进了正式附件

  C. 2042 年外业勘测日志
     - 关键字：陈星河、外业勘测、水质监测组、星河痕迹
     - 说明：人名被涂白过，说明记录口径已经发生过一次人为处理

  D. 2044 年数字化存档白纸
     - 关键字：实体文件依规销毁、数字档案见局内系统 /archive/2044/
     - 说明：这不是内容页，而是“内容被移走”的证明

核验逻辑：
  - 2040 → A1
  - 2041 → A2
  - 2042 → B1
  - 2044 → B2

叙事重点：
  - 2041 的荣誉附件让玩家意识到，检测不是独立完成的，临深集团的名字被写进了官方材料。
  - 2044 的白纸让玩家意识到，真正消失的不是档案，而是实体证据本身。
  - 2042 的陈星河签名与工位牌上的“陈██ / 星河痕迹”形成对应，说明人也被档案系统改写过。
  - 2040 的基准报告是整条时间轴的起点，告诉玩家这不是一份孤立文件，而是一整套被重新排序过的历史。

完成反馈：
  1. 最后一份材料归位时，档案柜内部会发出一声很轻的锁扣声。
  2. 屏幕右下角显示「归档核验完成」。
  3. 沈意独白：
     「原来不是丢了，是有人把它们换了位置。」
  4. 系统将【临深集团配合检测情况说明】、【2044数字化存档白纸】、【陈星河】三条发现加入当前发现栏。
  5. 玩家随后可点击荣誉牌匾右下角的蓝色便签，触发补充对白：
     「2041 年就已经把配合写进去了。」

补充规则：
  - 点击任一档案材料时，右侧年份格会短暂高亮可归位目标。
  - 若玩家先点年份格，再点材料，则视为取消目标，不影响进度。
  - 当前界面不使用复杂连线，只使用“材料 → 年份格”的直观归档交互。
  - 若玩家多次查看便利贴，会额外获得一条提示：
    「v2.3.1 比 v2.3 先出现，说明系统口径可以被回写。」

背景图具体视觉描述：

场景是一个临时征用的房间，从格局看原本可能是储藏室或者小型会议室——天花板比正常低半截，没有窗，只有一个被杂物挡住的通风口盖。

左区：
靠墙叠着几个黑色硬壳设备箱，金属扣件和橡胶边角都有使用痕迹，不是新的。信号屏蔽装置贴在墙上，体积比想象中小，就一块砖头大小的灰色盒子，侧面有绿色指示灯，地板上牵出一根电线绕进了接线板。接线板旁边地上还有几圈线，没有整理，像有人当时觉得之后还要拆，所以懒得绑。整个左区的光线最差，离两块屏幕最远，靠近了才能看清设备箱上的贴纸——大部分是系统版本号和资产标签，有一张被撕掉了一半，只剩胶的痕迹。

中区：
工作台是折叠式的，桌面有点不水平，沈意的键盘垫了一张对折的纸才稳。两块屏幕高度不一致，左边那块比右边稍高一点，用书叠起来垫的——书是什么不重要，只能看到侧面书脊，字看不清。两块屏幕是这个场景里唯一的光源，蓝白色，偏冷，把沈意脸的下半部分和手照亮，上半部分在阴影里。主屏亮度比副屏高，内容更密，是接入日志和镜像文件的界面；副屏偏暗，显示的是医疗委托记录，字号更大，像是给人直接阅读用的而不是操作用的。键盘是老款机械键盘，颜色已经从黑色磨成了深灰，Ctrl键和D键的键帽中央有明显的指纹磨亮的痕迹。沈意的手放在键盘上，没有打字，只是放着。

右区：
魏江站在右区最靠墙的角落，背对场景，面朝墙。他的身影是整个场景里唯一的人形剪影，但他不在画面焦点里——焦点是双屏和沈意的手。他旁边的地上放着一个旧外置硬盘，标签朝上，沈意那边能看见。水杯在设备箱盖子上，玻璃杯，水已经凉了，没有蒸气。魏江翻开的笔记本靠在墙脚，从沈意的角度只能看见最后一行字的笔画，看不清内容。

整体视觉基调：刻意隔离的空间。没有网络，没有干扰。这个房间里没有任何和外部世界的连接，连窗都没有。两块屏幕的蓝光是唯一的光，把一切压进阴影里，只有正在被操作的东西是亮的。魏江退在角落——这不是他的部分，这是沈意必须独自完成的。

场景互动元素
叙事静物：
1. 旧外置硬盘（右区）：贴着手写标签「备份-2046-03」，字迹是沈意自己的，她认出来了。标签下方一行更小的字：「仅本地，勿联网」——这是她当年给自己留的操作提示，意味着她备份时就知道这份东西不能联网存放。她保留了它，但已经不知道为什么保留了它。
2. 水杯（已凉，右区）：魏江放在那里之后就退到场景后方。玩家点击水杯时，沈意有一句内心独白：「他说了"需要的话叫我"，然后就不再说话了。这是这两天他做过的最好的事。」
3. 主屏桌面（中区终端）：桌面只有一个文件：「sys_backup_2046_0317.zip」。文件名的日期「0317」是本章全部关键时间戳指向的那天——玩家此时还不知道，但等到模块3支付残片确认后，会回头意识到这个文件名本身就已经是答案。
4. 信号屏蔽装置指示灯（左区）：绿色常亮，标签写「OFFLINE / 物理隔离已激活」。这个装置是魏江架设的，而非沈意。沈意看着它有一句内心独白：「他信任我，或者他不相信任何系统。两件事对他来说可能是同一件事。」
5. 旧键盘（中区工作台）：Ctrl键和D键的键帽磨损明显高于其他键。接入日志谜题中，沈意个人操作习惯的标志是「Ctrl+D → Alt+L → F7 → Ctrl+D」起始于Ctrl+D。磨损不是一次养成的，需要时间——这个键盘记录了那段时间。
6. 魏江留在远端的笔记本（右区背景，不可互动）：翻开但没被拿走，无法走近读取内容，只能隐约看到最后一行大字：「是谁——」句子没有写完。魏江退到场景远端，带着那个他还没说出口的问题等待。



第五章：记忆空间（内在记忆海）
背景图：视觉上难以区分沈意与郑和平的边界
2D横向平面布局
[左区]                         [中区]                              [右区]
有机记忆碎片区                  郑和平固化记忆块                      深层存档区
（情绪化，颜色偏移，边缘模糊）   （过度清晰，边界锐利，颜色饱和）       （模糊，边缘不规则，高密度排列）

                               （两种格式交接处，有格式冲突痕迹）      （数字坐标 + 手写标注混合形态）

背景图具体视觉描述：

整体空间是扁平的——不是三维纵深的洞穴或宫殿，而是一个被拉平的横截面，像一块巨大的软木板斜撑在视野里。背景是接近黑色的深蓝灰，带有极细的纵向纹路，像压平的纤维。没有天花板，没有地板，上下边缘向远处漫散开去，找不到边界。

左区有机碎片区：
碎片以不规则的矩形和三角形浮在空间里，每一块都像一张被晒褪色的照片——颜色整体偏黄偏橙，白色区域泛乌，本来应该是蓝绿色的部分变成了模糊的灰。碎片边缘不是直线，而是轻微参差的毛边，像被水泡过再撕开的纸张截面。碎片之间有极细的连线，白色，半透明，像蛛网或冻裂的玻璃纹——它们不是画出来的，是格式结构本身留下的痕迹。碎片会极缓慢地微动，不是飘，是像在水下随着呼吸轻微起伏。

中区格式交接带：
这是两种记忆格式的边界地带，没有明确的分界线，而是一个渐变区。左侧的毛边碎片和右侧的锐利碎片在这里互相穿插，有几块碎片被两种格式各占一半——一半颜色饱和、边缘清晰，另一半泛黄、边缘模糊。交接处有极细的光亮线，像金属被过度拉伸后的裂纹，不规则，会随着玩家靠近某块碎片而轻微移动。这个区域的背景底色比两侧稍亮一点，像被不均匀地照过光。

右区固化记忆区：
碎片质感完全不同——像从屏幕截图里剪下来直接放进这个空间的，颜色饱和度比周围高出一级，边缘是精确的直线或几何弧。数字、图表、坐标类内容用等宽字体呈现，清晰到有些不自然。碎片之间没有连线，独立悬浮，间距规则，像被程序整理过而不是被人记住的。它们不动。完全不动——在一个所有东西都在微动的空间里，静止本身是一种异常。

深层存档区（右侧边缘）：
越往右越密，碎片排列越来越紧，颜色越来越暗，最右侧几乎看不清内容，只剩轮廓。像一叠被压实的文件，最下面那几张已经贴在一起。这一区不是玩家操作的主要区域，它存在的意义是告诉玩家：这里的东西比看起来要多，大部分还压在下面。

整体视觉基调：这不是记忆宫殿。没有柱廊，没有走廊，没有戏剧性的光源。它更像一个工作台——有人在这里整理过很多次，把东西按照某种逻辑分区放置，然后中途停下来，再也没有回来。

场景互动元素
叙事静物（记忆空间内的对象，以记忆碎片形态呈现，而非现实物品）：
固化记忆碎片（郑和平的，过度清晰，无情绪噪声）：
1. 采样坐标卡片：数字精确到小数点后四位，但手感缺失——拿起来感觉不到纸的重量，没有折痕记忆，也没有「这张卡是在哪里写下来的」的情境附着。谜题阶段一中，这张卡片是判定「固化」格式的教学示例。
2. 化验报告截面：汞含量数值清晰可读，但零情绪痕迹——做这份报告时的日期、天气、疲劳感全部不存在。报告上有一行手写批注：「样本编号C-03-2046，送检2046.04.11」，日期与第二章B的价格骤跌节点高度接近，这条时间呼应是阶段二证据链拼接的关键节点之一。

有机记忆碎片（沈意自身的，已被侵扰）：
4. 一段模糊的医院走廊：颜色偏黄，脚步声异常响，情绪强烈（焦虑/压迫感）但细节缺失。沈意无法确认这是否真实发生过——但它在她的有机记忆里，不是郑和平的。这段走廊对应的是她2046年9月进入苍屿医院的记忆，她的清洗不彻底。

核心谜题：格式鉴别 + 证据链拼接（两阶段）

阶段一：格式鉴别（视觉属性判断谜题）
玩家面对12块记忆碎片（以不同视觉质感的「卡片」呈现），逐一点击，根据以下视觉和交互属性判断类型：

固化特征：清晰度异常高，无情绪附着，鼠标悬停时碎片边缘保持锐利
有机特征：颜色偏移，边缘模糊，悬停时会短暂「呼吸」（边缘轻微扩张收缩）
混合格式：两种视觉痕迹共存，悬停时边缘一半锐利一半模糊

陷阱碎片（MEM-09）：视觉上完全符合固化特征，内容也极度完整，但结构层有异常——悬停时间超过3秒后，边缘会出现极细微的颤动（格式错误的迹象）。大多数玩家会直接将它判断为「固化」并放进证据链；若选错，阶段二拼接时这块碎片会导致一条链节点错位，无法完成完整拼接。
正确答案：MEM-09 = 混合格式（四级干预转移过程产生的格式污染副产品）

阶段二：证据链拼接（节点排序谜题）
筛选出的有效固化碎片以「浮动节点」形式散布在屏幕上，玩家用连线将它们按内部逻辑连接：

     ↓ 地点对应
污染物化验数据（汞含量，2046.04.11）
     ↓ 成分溯源
地下管道走向图（精炼厂 → C-03海底）
     ↓ 时段对应
排污时间表（与价格骤跌节点交叉确认）
     ↓ 空间对应
苍屿症发病分布图（码头片区为圆心）

每连接一条正确的线，接缝处出现光亮，碎片边缘格式趋于一致。全部连接完成时，触发叙事过场。

【完成节点】
证据链全部拼接完成后叙事过场开始。过场结束后沈意回到现实，屏幕亮起。

叙事静物：

结局C：沉默交换

操作一：阅读协议
苏临的和解建议书PDF在副屏上，从阶段一就在那里了，滚动位置停在第三页。玩家需要手动滚动到底部才能进行下一步——没有强制阅读检测，但协议很长，条款密集，语言格式化，每一条都用平静的措辞在说同一件事：这件事就此结束，永远结束。

正文最后一段是苏临唯一一次在书面上承认「事件存在复杂性」，用的词是「复杂性」，不是「错误」，不是「伤害」。这段话没有高亮，没有任何方式提示玩家它是异常的——它就在那里，和其他条款一样，格式相同，字号相同。

均自动切换至阶段三（尾声）。

第六章阶段三：尾声
与序章同一场景（沈意出租屋），布局参照序章。

背景图具体视觉描述：

回到序章的那个房间。是白天，窗帘推到一侧，窗外港区的灯在白天几乎看不见，但还亮着，隐约可见灯柱轮廓。光线角度和序章不同——序章是早晨偏冷的侧光，现在是上午偏正的散光，整个房间比序章时稍亮，阴影少了一点锐度。

房间的格局没有变：靠墙书架、压在桌角的旧工牌、椅背上的外套。书架上几本书的位置和序章一致，没有人动过它们。椅背上的外套还是同一件，但领口压的方式不同，像是穿过又脱下来的。

桌面是变化的唯一区域。序章时桌上是魏江的邮件、没喝完的咖啡、几张便利贴；现在便利贴不在了，咖啡杯还在，但是空的，杯壁内侧有一圈干燥的棕色痕迹，喝完有一段时间了。杯子没有被收走，像是放在那里忘记了，或者没有必要收。

沈意不在画面里——和序章一样，她是视角，不是被观看的对象。整个尾声里玩家只看见她的视角，直到最后的互动动作触发。
